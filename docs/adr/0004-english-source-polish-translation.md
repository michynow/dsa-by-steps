# English is the source language; Polish is a required translation

All Captions and interface text are authored in English and translated to Polish. A Lesson cannot build unless both Locales define every key. Code, identifiers, Test names, runner output, and Terms stay English in both Locales, with a Term's Polish equivalent shown once on first use. The default Locale follows the browser and the Learner's choice is remembered.

## Considered Options

- **English only**: half the authoring cost, rejected because the Course targets Polish-speaking Learners too.
- **Translating code and Terms**: rejected because interview and documentation vocabulary is English; Learners must recognise it.
