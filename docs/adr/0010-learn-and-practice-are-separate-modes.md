# Learn and Practice are separate modes

The Course has two modes, switched in the header. **Learn** walks through a Lesson's Steps and asks Checks inline, styled as a distinct "Your turn" card so teaching and testing never look alike. **Practice** holds the coding Exercises, one per Lesson, reached from the Practice tab or a "Practice this" button at the end of a Lesson. The Step Rail no longer ends in an Exercise entry. Mixing explanations, Checks and code in one column confused what was teaching and what was testing.

## Considered Options

- **Strict split with no inline Checks**: matches the reference course, but loses the predict-then-watch loop of ADR 0009.
- **One flow, restyled only**: smallest change, but leaves the confusion between Steps and the Exercise.
